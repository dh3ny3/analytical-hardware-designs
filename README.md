# Analytical Hardware Designs

Open-source CAD designs for analytical chemistry hardware, inspired by industry standards. Built with AutoCAD and Zoo Design Studio.

## Purpose
This repository documents CAD designs for analytical chemistry hardware intended to address limitations in standard laboratory equipment. Each design targets specific functional requirements where commercial solutions are inadequate or unavailable.

## Design Inventory

### GC-Thermal-Desorption-Tube_ThinWall-RevA.dwg
CAD reconstruction of Agilent-style TD tube for practice and specification analysis.
- Replicated thin-wall geometry (6mm OD / 4mm ID) per industry standards
- Modeled standard compression fitting interfaces
- Status: Reference Model (Non-Original Design)

### Benchtop-Dispensing-Bracket.dwg
Original prototype dispensing arm with orthogonal swing mechanism.
- Modular grip inserts for glassware diameters 5–25mm
- Lateral displacement capability for thermal isolation during heated reactions
- Status: v0.1 Prototype [DRAFT]
